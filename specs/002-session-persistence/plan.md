# Implementation Plan: Session Conversation Persistence

## Summary

Session conversation persistence allows the chatbot to remember all prior messages within a single terminal session, giving the LLM full context for follow-up questions. Research confirmed this feature is **already fully implemented** in `chat.py` and `src/agents.py` — no code changes are required.

**Project Type**: CLI chatbot

## Phase 1: Design

See [data-model.md](data-model.md) and [quickstart.md](quickstart.md).

No new design required. The existing design is:

```
history = list[{"role": str, "content": str}]
  → passed to get_reply() on every call
  → extended with [system] + history + [current user message] → LLM
  → user + assistant appended after each successful exchange
  → trimmed to last 40 on overflow
  → cleared on limpar/clear command
  → discarded on process exit
```
